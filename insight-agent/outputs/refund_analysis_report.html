行动建议

  • 【商品质量】商品质量问题占退款 21.12%，建议重点排查近 3 个月投诉集中的 SKU，联合质检/供应商进行改善
  • 【尺寸/规格】占 19.74%，建议优化商品详情页的尺码表、规格说明，增加「尺码助手」或人工客服推荐功能
  • 【用户拒收】占 19%（53 笔），建议分析拒收订单的地域分布和配送时长，优先改善物流体验差的区域
  • 【支付宝渠道】退款占比 34.32%，需确认是否与支付宝用户基数匹配；如果退款率显著高于其他渠道，应排查支付链路问题
  • 【6 月异常】6 月支付量大增但退款金额下降，需持续监控 6 月下半月退款数据，防止滞后期影响

附录：口径说明

  • 时间口径：退款成功时间（refund_success_time），2026-03-01 ~ 2026-06-08
  • 状态过滤：仅统计 refund_status = '退款成功'，不含审核中/已拒绝/已关闭
  • 金额单位：所有金额字段已从「分」转为「元」（* 0.01）
  • 退款率(金额) = SUM(refund_success_amount) / SUM(paid_amount)，同时间窗口
  • 退款率(订单) = COUNT(DISTINCT refund_order_id) / COUNT(DISTINCT pay_order_id)
  • 地域数据：用户省份字段因数据关联缺失为空，暂无法做地域维度分析
  • 数据来源：dwd_fact_trade_refund_detail_di / dwd_fact_trade_pay_detail_di
